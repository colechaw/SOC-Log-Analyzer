# SOC-Log-Analyzer

## Student Project Overview

This repository is a student project focused on learning cybersecurity basics by creating a simple SIEM (Security Information and Event Management) tool.

The goal is to build practical skills in log analysis, threat identification, and incident tracking through hands-on development.

## Ongoing Development

This project will be continuously updated as I learn and progress. Over time, the SIEM tool will be improved to better detect, record, and organize potential security threats.
